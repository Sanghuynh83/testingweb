# Bài tập: Săn lùng Bằng chứng Xã hội (Social Proof)

**Mục tiêu:** Rèn luyện khả năng "nhận diện" các loại bằng chứng xã hội trong thực tế.

**Yêu cầu:**

1.  Mở 3 trang web bạn hay truy cập (ví dụ: Shopee, Tiki, một landing page bán khóa học, một trang SaaS).
2.  Chụp ảnh màn hình và liệt kê ít nhất **4 loại** Bằng chứng Xã hội khác nhau mà bạn tìm thấy.
3.  Ghi rõ nó thuộc loại nào (theo lý thuyết) và tại sao bạn nghĩ nó hiệu quả.
